Model risk & limitations

What could make this wrong

An actuarial standard of practice requires disclosing a model's limitations alongside its results. Overconfidence is the fastest way to lose a working actuary's trust — so here is every real, specific way this project's own data and methodology can fail, stated plainly, not buried in a terms-of-service page.

Corrections made

The VERIFIED/REPORTED discipline this site uses only means something if mistakes get fixed in the open, not quietly reworded. Every correction below is real, not illustrative — found during this project's own verification passes, fixed, and left on the record here instead of in a commit message nobody reads.

Wrong date, corrected

Meta insurer-coverage ruling: stated as April 2026, actually February 27, 2026

A timeline entry carried a wrong date (likely drifted in from secondary coverage, not the ruling itself) across the pipeline source and three already-exported data files. Caught during a fresh verification pass while sourcing an unrelated milestone, corrected everywhere it appeared, not just the one place it was first noticed.

Caught before shipping

A fabricated source URL was guessed, then caught by its own verification step

A plausible-looking NIH press-release URL was typed from memory for a real milestone, rather than found live. Before publishing, the URL was opened directly — it was a real 404 — and replaced with a verified-real news URL instead. The catch came from this project's own "always verify live" discipline working as intended, not from an outside review.

Shipped thin, then fixed

Geographic correlation was n=1 (Michigan only) for one round, then expanded to 45 states

The contamination-site × cancer-incidence correlation table went live honestly labeled but structurally thin — only Michigan had a real tracked contamination-site source. Rather than leave it as a one-state proof of concept, a second real national source (EPA's own PFAS Analytic Tools) was found and added, taking it to 45 states/territories.

Found and fixed

A silent data bug: leading whitespace collapsed real multi-state counts

EPA's own national PFAS Superfund dataset returns state codes with a leading space (" MI", not "MI") on every row. Unnoticed, this would have silently split every state's real site count into two separate, wrong buckets. Caught by inspecting the actual rendered table output, not assumed correct because the pipeline ran without errors.

Honest non-result

The momentum score does not reliably track eventual settlement size

Joining the real backtest scores against this project's own real, dated settlement amounts shows PFAS's momentum and real settlement size trending up together through 2023 — but talc's momentum score actually fell in later years while its real settlement size kept rising. Shown as-is on the Validation page, not reworded into a cleaner story than the data supports.

Data coverage
Curation gap

Only 5 companies have sourced severity data

Every quantified dollar figure traces to one of 5 curated companies (3M, DuPont, Chemours, Corteva, J&J). A company outside that set showing no signal means not yet checked, never "checked and cleared" — this is stated on every relevant screen, but it bears repeating here: absence of a flag is not evidence of absence of risk.

Empty table

SDWA drinking-water violations: 0 rows on file

sdwa_pfas_violations exists in schema and was built against a real, verified live EPA ECHO endpoint, but has only ever been run against one state (Michigan) in a prior session and currently holds no persisted rows. This is a real, known gap, not a silently-empty feature pretending to be complete.

Found and excluded

Litigation filing-velocity: a real data artifact, not a feature

While building the Emergence Signal, every plaintiff_network row tagged risk_category='pfas' was found to share the identical date_filed value (2018-09-25) — a batch-import placeholder, not 63 real distinct filing dates. The component was dropped rather than reported. If this is fixed upstream, filing velocity could become a real fourth Emergence Signal component.

Scope limit

8-K scanning checks recent filings, not the full history

material_event_pipeline.py checks only the most recent N 8-Ks per curated company for a same-document keyword co-occurrence — by design, to stay fast and keyless against SEC EDGAR's rate limits. A real material PFAS/talc event disclosed further back in a company's filing history, before this pipeline's coverage window, would not appear here.

Statistical limitations
Small-N noise

Growth percentages from single-digit counts are directionally real, not statistically precise

PFAS's legislative-velocity component, for example, is a real 120% growth rate — computed from 5 enactments in one period vs 11 in the next. That is a genuine signal, but a percentage computed off single-digit counts moves a lot with one or two additional data points. The Validation page flags this explicitly for the 6PPD-quinone discovery candidate (prior-period base of ~21 publications/year); the same caveat applies, in degree, to every small-count component here.

Keyword matching

False negatives and false positives are both real possibilities

Every pipeline that scans text (8-Ks, PubMed abstracts, legislative bill titles) matches on keyword co-occurrence. A real settlement disclosed in unusual language could be missed (false negative); a routine mention in an unrelated context could, in principle, pass a keyword filter without representing real liability exposure (false positive). Every hit here is still a human-reviewable snippet with a source link specifically so this can be checked, not just trusted.

No causal claim

A rising signal is correlation, never causation

Scientific-literature momentum, legislative velocity, and 8-K frequency are leading indicators this project's own research found associated with past mass-tort emergence (asbestos, PFAS, talc) — not a proven causal mechanism. The backtest shows this pattern held for 2 real categories; it is not a law of litigation.

What would break the signal
Legal reversal

A landmark pro-defendant ruling or federal preemption

A successful federal-preemption defense (precedent exists in other product categories) or an unfavorable-to-plaintiffs appellate ruling in a bellwether case could sharply reverse real filing activity in a way these leading indicators would only show with a lag — scientific and legislative momentum would keep climbing even as the litigation pathway itself narrows.

Regulatory reversal

An EPA rule change or vacatur

The real PFAS National Primary Drinking Water Regulation (finalized April 2024) is a structural input behind several of this project's real signals. A future administration rolling back or a court vacating that rule would remove a real regulatory tailwind this project currently treats as durable.

By design

This is decision support, never a substitute for actuarial or legal judgment

Every module in this project repeats some version of this, deliberately: nothing here is an actuarially-certified reserve estimate, a legal opinion, or a guarantee of coverage outcome. It is one real, falsifiable, sourced input among the several a working underwriter or actuary should weigh.

This page exists because an honest account of what could be wrong is more credible than a confident account of what's right. See the Methodology Validation page for what has actually been tested, and every module's own inline VERIFIED/REPORTED tiers for source-level confidence on each individual figure.
