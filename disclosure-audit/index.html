The VDR says nothing. The federal government disagrees.

A real, verified LMA panel (Beazley, Mosaic, Ascot, Norton Rose Fulbright — 29 Sep 2026) named disclosure adequacy as a leading cause of contested W&I claims. What this actually is, and its real limits

Stated honestly, same discipline as every other tool on this site:

  • EPA ECHO: real, free, keyless live search. Covers Clean Air/Water/RCRA/SDWA facility compliance.
  • OSHA (DOL Open Data Portal V4): requires a free DOL_API_KEY on the server running this check -- without one, this check is skipped cleanly and disclosed, not silently dropped.
  • USAspending: real, free, keyless. Only surfaces awards where the target is the actual federal contract recipient, not just mentioned in a product description.
  • FDA OAI inspections are NOT checked. Checked live before building this: FDA's inspection-classification dashboard is a session-ticketed Qlik Sense BI application, not a stable public API -- scraping an interactive BI session is a fundamentally less reliable integration than every other source here, so it's left out rather than faked.
  • Parent Name vs. Plant DBA Mismatch: EPA/OSHA records inspections under the local operating plant's name, not necessarily the Delaware holding-company name on the front of the slip. Always supply the subsidiary/facility name from the deal's own schedule.
  • Entity resolution (GLEIF, not DUNS): Dun & Bradstreet's DUNS lookup has no free API -- checked live before ruling it out. GLEIF's Legal Entity Identifier registry does, and it carries real parent/subsidiary relationship data, not just a name match. Confirmed live on this exact "Janssen Pharmaceuticals vs. Johnson & Johnson" scenario -- try the third example button above. LEI coverage skews toward financial-market participants, so a facility-level DBA with no LEI on file is a real, common "not found," not a bug.
  • A match is a real federal enforcement record under this name -- not a legal finding that the seller breached a specific warranty.
  • Point-in-time replay: set an as-of date to see what this would have shown on a past bind date, not just right now. OSHA and USAspending use real, exact dated fields (inspection-open date, award-start date). EPA ECHO uses its own rolling quarterly compliance-history strings, with quarter boundaries estimated by counting backward from today rather than read from ECHO's own boundary metadata -- disclosed as quarter-resolution, not exact, every time it's used.
