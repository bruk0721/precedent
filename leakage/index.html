Do presumption laws and PFAS litigation connect?

A real mentor review asked a sharp question Nubuye had never actually tested: does an easier path to a paid workers'-comp claim change the real PFAS/AFFF signal in that state? This is the first time the Presumption Expansion Tracker and the PFAS tracker have been read together. The honest answer below is a partial one — it tests correlation with real signal, not the litigation-substitution question itself, which needs data Nubuye doesn't have yet.

What this does and doesn't test

The real numbers

Presumption status is each state's real 2023 coverage (cancer, cardiovascular, or PTSD presumption — any of the three) from the Presumption Expansion Tracker's own NCCI-sourced data. PFAS signal is Nubuye's own real legislative and exposure-site data, joined by state for the first time.

A real, honest divergence worth sitting with: presumption-law states show fewer real PFAS exposure sites on average, but more real PFAS regulation bills. Those point in opposite directions — not a clean story, and not forced into one.
