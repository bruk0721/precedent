Is a mass tort's real federal filing rate accelerating?

Checks real federal MDL docket filings on CourtListener/RECAP, centralized under the JPML court, for a keyword like AFFF, talc, hair relaxer, or paraquat — same recent-vs-prior-window shape as CPSC Recall Velocity.

Honest status, stated plainly: every other live check on this site was confirmed against a real response before shipping. This one couldn't be. CourtListener requires a free, user-registered API token for every endpoint — confirmed live while building this, even anonymous read-only search returns a real HTTP 401. This tool is built against CourtListener's own documented v4 schema, but is genuinely untested against real data until someone sets COURTLISTENER_API_TOKEN with their own free token (register at courtlistener.com/profile/api-token).

Run this locally first

Same live-lookup architecture as every other tool here -- this is not pre-computed into the static site export. Set your own free token before checking a keyword:

cd precedent-prototypes/api-backend
pip install -r requirements.txt
export COURTLISTENER_API_TOKEN=your-free-token-here
uvicorn main:app --reload --port 8000

What this actually is, and its real limits

Stated honestly, same discipline as every other tool on this site -- more so here, since this one is unverified:

  • Federal MDL dockets only, uploaded to RECAP via PACER. Real state-court mass-tort litigation -- including talc's real jury verdicts -- is structurally invisible to this check.
  • Schema not individually confirmed live. date_filed range filtering and the "jpml" court-id slug follow CourtListener's documented double-underscore lookup convention, but neither was confirmed against a real authenticated response before shipping. A real schema mismatch will surface as an upstream error, not a silently wrong count.
  • Rate limit is real and tight. CourtListener's free tier caps at 5 requests/minute, 50/hour, 125/day. This check alone uses 3 calls.
  • Keyword matching against case name is substring-based -- same over/under-match caveat as every other keyword check on this site.
  • NAAG's state-attorney-general settlement tracker, the other half of a complete litigation-ontology picture, has no API at all and isn't attempted here.
