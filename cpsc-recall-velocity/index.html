What this actually is, and its real limits

Stated honestly, same discipline as every other tool on this site:

  • This is recall-level velocity, not pre-recall complaint-level signal. By the time something is a CPSC recall, a manufacturer or CPSC has already acted. SaferProducts.gov's real complaint-level OData API returned a confirmed HTTP 401 without a free CPSC-issued application key while building this -- that's the real pre-recall signal this feed is eventually named for, and it isn't wired in yet.
  • NHTSA is not checked here. Its real, confirmed complaints API needs an exact vehicle make/model/modelYear, not a free-text category -- it doesn't fit this feed's shape, so it's left out rather than forced in dishonestly.
  • CPSC's own acknowledged taxonomy gap: CPSC's September 2025 preliminary regulatory analysis states its fire-incident data has no product category for lithium-ion batteries at all -- any velocity read on a battery-related keyword understates true incidence. This tool surfaces that caveat automatically when a battery/micromobility keyword is used, rather than letting a rising number look more precise than it is.
  • Keyword matching is substring-based against CPSC's own recall text -- it can over-match (an unrelated recall sharing a word) and under-match (a real recall using different wording).
  • A window-over-window change can reflect CPSC's own publication cadence or seasonality, not a real underlying shift.
