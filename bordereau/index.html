A whole bordereau in one pass, not one typed name at a time

Upload the book. Get every row checked.

A real bordereau isn't 5 names, it's thousands. This takes a real CSV of company names, splits it into batches, and runs every one through the same real checks as the single-company tools — returning a CSV you can drop straight back into your own workbook, with a flag, match count, and source list appended to every row.

Run this locally first

Same real local API as the Disclosure Auditor and every other live-lookup tool here:

cd precedent-prototypes/api-backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

Upload a bordereau CSV

One column of company names -- a header row named company_name (or name) is used if present, otherwise the first column. This reads /v1/submission-check-batch, which checks AI-agent-liability dockets, SEC 10-K risk factors, SEC 8-K cyber filings, curated settlement amounts, plaintiff-firm dockets, and material-event filings -- the same real sources the Submission Auto-Check tool uses for a single name. It does NOT run the Disclosure Auditor's live EPA/OSHA/USAspending/GLEIF checks per row -- see the real limits below for why.

Results

What this actually is, and its real limits

  • Not "nothing leaves your browser": unlike a page that only renders a pre-computed export, this one POSTs your uploaded names to whatever API base URL is set above (your own local API by default). Said plainly, not hidden behind the phrasing used elsewhere on this site.
  • Batching: /v1/submission-check-batch is capped at 500 names per call (it's reading a fast, pre-computed snapshot, not a live external call) -- a 5,000-row bordereau is automatically split into 10 sequential requests, shown in the progress bar.
  • Name-based matching only: exact substring match on a normalized legal name, same real limitation as every single-name tool here. A zero-match row means nothing was found under that exact name, not "cleared."
  • Why not the Disclosure Auditor's live checks here too: EPA ECHO/OSHA/USAspending/GLEIF are LIVE external calls per name, already capped at 50 per batch specifically because of that cost (see /api/). Running that across a 5,000-row bordereau in a browser tab isn't realistic -- the honest path for that scale is the batch endpoint directly from a server-side job, not this page.
  • CSV parsing here is intentionally simple (comma-split with basic quote handling) -- a field containing a literal comma inside unescaped quotes can misparse. Re-export from Excel/Sheets as standard CSV if a row looks wrong.
